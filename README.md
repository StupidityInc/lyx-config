# lyx-config

My personal LyX editor configuration — preferences, macros, templates, and keybindings.

## Contents
- **`preferences`** — LyX user preferences file
- **`bind/user.bind`** — Custom keybindings
- **`Macros/`** — Reusable LyX macros (e.g., `Macros_Standard.lyx`)
- **`Templates/`** — Document templates (e.g., `Assignments.lyx` for homework)
- **`Sources/`** — Additional source files
- **`.gitignore`** — Standard LaTeX build artifacts ignore list

## Usage
Clone and symlink or copy into your LyX user directory:
- **Linux:** `~/.lyx/`
- **macOS:** `~/Library/Application Support/LyX-2.3/`
- **Windows:** `%APPDATA%\LyX2.3\`

See [AutoCustomLyX](https://github.com/StupidityInc/AutoCustomLyX) for an automated installer.
